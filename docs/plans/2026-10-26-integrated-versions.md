# 三版本整合

用户保留并改名的程序：桌面蟑螂-校准版.exe、桌面蟑螂-质感版.exe、桌面蟑螂-fxq版.exe。
界面名称严格沿用：校准版、质感版、fxq版。

采用单窗口类型下拉框与数量输入，每次生成只追加所选类型；三类可以共存。暂停、清空、速度上限和退出统一控制；所有类型合计不超过 100 只。

现有源码已历经多次迭代，并不能直接重建这三个保留版本的所有细节。直接共用最新绘制逻辑会改变校准版的腿部外形；启动三个外部 EXE 则不满足单窗口和独立便携需求。因此将用户保留的三个 EXE 作为只读资源嵌入整合程序，通过 .NET 反射调用各自现有的 Population、RoachRenderer、RoachWindow。读取前已验证三个文件都具有匹配的接口。

不调用原 EXE 的入口点，不启动子进程，不解压原程序，不创建隐藏的旧控制面板。只构造原模型、渲染器和必要的透明覆盖窗口；整合面板维护一个时钟。内嵌程序集保持各自的素材、腿位、尺寸和动作，完全复用用户选择的原始文件。

验收：三个后缀名称正确；2+3+4 混合生成成功；切换不替换旧类型；全局暂停/继续及暂停时生成；合计上限原子拒绝；33+33+34 容量；清空所有类型；关闭面板释放全部覆盖窗口；多轮生成清空 GDI 回收；原覆盖窗口保留穿透、不抢焦点和屏幕边界；独立文件夹运行不依赖原 EXE 路径。
