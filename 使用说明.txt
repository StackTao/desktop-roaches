桌面蟑螂 · 融合清晰版（便携版）

- 选用上一张嘟嘴照片作为脸部参考，其五官和表情比第二张照片更清楚。
- 脸、下巴过渡、前胸甲壳和腹部改为一体生成的透明素材，统一光照，去掉单独贴头像的接缝。
- 默认随机体型参数从 58～125 增至 110～165；100% 显示缩放时，头身总长约 103～155 像素（不含触角和腿）。
- 保留细长腹部、独立大小、六足落脚支撑、巡走/快跑/停顿、转向和触角动画。
- 素材全部内嵌 EXE，单独复制 EXE 即可运行。

一体素材由内置 image_gen 参考用户照片生成，保留嘟嘴表情并调整脸与甲壳的衔接。
预览 GIF 右侧按 100% 显示缩放的程序绘制尺寸生成；查看器缩放图片会改变看起来的大小。

一、运行
双击“桌面蟑螂-融合清晰版.exe”（或项目目录的“桌面蟑螂.exe”）即可。
如果旧版仍在运行，请先从旧版控制面板退出，再打开新版。图片已内置，单独复制 EXE 到其他文件夹也能运行。
适用 Windows 10 / 11，使用系统自带的 .NET Framework 4.x；不需要安装 Java 或 Python。
启动时不会自动产生蟑螂。

二、操作
1. 设置“每次生成”数量，范围 1～100，默认 5。
2. 每点击一次“生成一批”，就追加完整的一批，已有的继续活动。
3. 总量最多 100 只。若剩余额度不足，整批不添加，调整数量后再点。
4. “速度上限”控制每只蟑螂的最大移动速度，默认 180；实际速度和停顿独立随机变化。
   显示缩放为 100% 时，速度单位是像素/秒；更高缩放时按比例换算。
5. “暂停 / 继续”控制所有蟑螂；暂停期间可以添加，新添加的保持暂停。
6. “全部清空”立即移除所有蟑螂。
7. 点击“退出”或关闭控制面板，所有蟑螂和程序一并退出。
8. 面板最小化后，从任务栏恢复。

三、快捷键
Ctrl + Alt + C：全部清空。
Ctrl + Alt + Q：退出程序。
如果系统限制或其他程序占用快捷键，面板会提示不可用，请使用面板按钮。

四、活动规则
只在主屏幕的可用桌面区域活动，避开任务栏；多屏下不会跑到副屏。
每只蟑螂独立随机变速、转向，并有明确的暂时停顿，随后自行继续。
接近边缘时提前减速、连续转向屏幕内，整个身体、腿和触角不会跑出活动区域。
蟑螂之间可互相穿过，不计算碰撞。
透明蟑螂窗口在普通窗口上方显示，但不接收鼠标点击，不影响操作下面的软件。
分辨率或任务栏位置改变后，自动重新限制位置。
独占全屏游戏、锁屏、安全桌面等系统特殊界面不保证覆盖显示。

五、程序行为
不联网，不修改开机启动，不写注册表，不后台驻留，不需要管理员权限。
关闭面板即可完全退出；再次启动会恢复默认设置和空桌面。

本机短时测试：默认 5 只约 40 帧/秒；100 只约 12 帧/秒。实际流畅度随数量与电脑性能变化。

源码、素材和构建脚本随项目目录保存；日常使用只需要 EXE。
在安装了 .NET Framework C# 编译器的机器上，用 PowerShell 运行 build.ps1 可重新构建；
运行 .\build.ps1 -Test 可执行运动模拟和 Windows 窗口集成检查（检查时会短暂显示蟑螂）。
